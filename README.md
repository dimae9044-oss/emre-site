# emre — бот для стримеров

`emre` — Telegram-бот и сайт для стримеров. Бот публикует в Telegram-канал стримера уведомление и ссылку на Twitch, когда начинается эфир.

- Публичная витрина с примером поста и оплатой по СБП
- Админка: стримеры, заявки, подтверждение оплаты, настройки, бэкапы
- Отправка уведомлений через `POST /announce` (токен бота хранится только на сервере)
- AI-агент и Telegram Mini App

## Структура

```text
.
├── index.html          # витрина
├── styles.css          # чёрно-фиолетовая тема, адаптив
├── app.js              # логика сайта и админки
├── server.ps1          # локальный сервер: раздаёт сайт и шлёт в Telegram
├── worker-public.js    # готовый Cloudflare Worker для публикации в интернет
├── ai-agent/           # AI-агент и Mini App
│   ├── worker.js
│   ├── local-agent.ps1
│   ├── miniapp.html
│   └── wrangler.toml
└── .env.example        # шаблон секретов
```

## Локальный запуск

```powershell
# 1. Скопируй .env.example → .env и заполни секреты
Copy-Item .env.example .env

# 2. Запусти сервер
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

Открой `http://localhost:8787/`. Проверка бота: `http://localhost:8787/health`.

Пароль админки задаётся константой `CURRENT_ADMIN_PASSWORD` в `app.js`.

## Секреты

**Никогда не коммить `.env`** — там токен бота. Для публикации используются переменные окружения:

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота, только на сервере |
| `ADMIN_TOKEN` | секрет для `/announce` |
| `TELEGRAM_CHAT_ID` | резервный чат для тестовых сообщений |
| `BOT_NAME` | имя бота в подписи поста |

## Публикация (Cloudflare Worker)

`worker-public.js` — самодостаточный воркер: внутри него уже лежат HTML/CSS/JS сайта и Mini App.

1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Worker** → **Hello World** → **Deploy**.
2. **Edit code** → замени весь код содержимым `worker-public.js` → **Deploy**.
3. **Settings → Variables and Secrets** → добавить `TELEGRAM_BOT_TOKEN`, `ADMIN_TOKEN`, `TELEGRAM_CHAT_ID`, `BOT_NAME`.
4. Готово:
   - сайт — `https://<имя-воркера>.<аккаунт>.workers.dev/`
   - Mini App — `https://<имя-воркера>.<аккаунт>.workers.dev/app`

Адрес воркера подставляется автоматически: на HTTPS-странице сайт использует свой же origin.

# emre — бот для стримеров

`emre` — Telegram-бот и сайт для стримеров. Бот публикует в Telegram-канал стримера уведомление и ссылку на Twitch, когда начинается эфир.

- Публичная витрина с примером поста и оплатой по СБП
- Админка: стримеры, заявки, подтверждение оплаты, настройки, бэкапы
- Отправка уведомлений через `POST /announce` (токен бота хранится только на сервере)
- AI-агент и Telegram Mini App

## Структура

```text
.
├── index.html          # витрина
├── styles.css          # чёрно-фиолетовая тема, адаптив
├── app.js              # логика сайта и админки
├── server.ps1          # локальный сервер: раздаёт сайт, хранит состояние и шлёт в Telegram
├── stream-monitor.ps1  # следит за Twitch и публикует анонсы только оплатившим стримерам
├── worker-public.js    # готовый Cloudflare Worker для публикации в интернет
├── ai-agent/           # AI-агент и Mini App
│   ├── worker.js
│   ├── local-agent.ps1
│   ├── miniapp.html
│   └── wrangler.toml
└── .env.example        # шаблон секретов
```

## Локальный запуск

```powershell
# 1. Скопируй .env.example → .env и заполни секреты
Copy-Item .env.example .env

# 2. Запусти сервер
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

Открой `http://localhost:8787/`. Проверка бота: `http://localhost:8787/health`.

Состояние админки сохраняется на сервере в `data/state.json` (и дублируется в `localStorage`), поэтому мониторинг видит стримеров и их подписки.

Пароль админки задаётся константой `CURRENT_ADMIN_PASSWORD` в `app.js`. Подсказка с паролем под формой входа убрана.

## Вход и оплата на сайте

1. Нажми **«Войти»** в шапке и введи Telegram-логин (`@name`) и пароль аккаунта. Неизвестный логин → **«Такого аккаунта не существует»**, неверный пароль → **«Неверный пароль»**.
2. Для новых пользователей есть ссылка **«Нет аккаунта? Создать»** — при регистрации задаётся пароль (минимум 6 символов) и подтверждение; аккаунт сразу становится текущим.
3. Пароль хранится только как хеш в `localStorage`/`state.json`, в ИИ и в Telegram он не отправляется. Для демо-аккаунтов `@nainangel` и `@dimstream` пароль `604Ss1480`.
4. В окне входа и в футере есть кнопки с иконками **Telegram** (`@emeranonsbot`), **Twitch** и **Google**. Ссылки открываются через `Telegram.WebApp.openLink` внутри Mini App и через `window.open` в браузере (с запасным переходом, если popup заблокирован). Если сайт открыт как Mini App и у Telegram-пользователя есть аккаунт в emre — кнопка Telegram сразу авторизует его. Для Twitch и Google нужен вход по логину и паролю emre: полноценный OAuth требует client ID/secret и сервер, их пока нет.
5. После входа логин показывается в шапке; оплата доступна только авторизованным пользователям.
6. В окне оплаты есть поля «Имя стримера», «Twitch-логин», «Telegram-канал для постов», «Ссылка на Twitch (необязательно)» и «Последние 4 цифры перевода (если есть)». Значения подставляются из аккаунта автоматически, но их можно изменить. Перед отправкой заявки проверяются аккаунт, Twitch-логин и канал.

## Звуки интерфейса

- При любом клике воспроизводится короткий щелчок, при наборе текста в полях — тихий тик, при успешных действиях — сигнал, при ошибках — низкий тон.
- Звуки синтезируются через Web Audio API, внешние аудиофайлы не нужны.
- Кнопка `🔊 / 🔇` в шапке включает и выключает звуки; выбор сохраняется в браузере.

## ИИ-проверка

ИИ-проверка включена на все данные сайта (Pollinations, без API-ключа):

- в шапке есть индикатор `🤖 ИИ: всё ок` / `🤖 ИИ: N замечаний` — после каждого сохранения проверяются аккаунты, стримеры, заявки и настройки;
- при входе, регистрации, оплате и добавлении стримера ИИ дополнительно проверяет формат логинов, каналов и ссылок;
- в окне оплаты ИИ-проверка запускается **сразу при открытии**, до нажатия кнопки, и повторяется перед отправкой заявки;
- если внешний ИИ недоступен или требует оплату, автоматически включается встроенная локальная модель — проверка при оплате всегда работает;
- токен бота и пароль админки в ИИ не отправляются.

## Автоанонсы стримов (только после оплаты)

1. Добавь `@emeranonsbot` в нужный Telegram-канал и выдай ему право **«Отправлять сообщения»**:
   канал → **Administrators** → **Add Admin** → найти `@emeranonsbot`. Бот не может сделать себя админом сам — это делается вручную в Telegram.
2. В админке сайта добавь стримера: Twitch-логин, ссылка на Twitch и `@username` канала (или числовой chat id).
3. После перевода 200 ₽ подтверди заявку кнопкой **«Подтвердить»** — у стримера появится `paidUntil`.
4. Запусти мониторинг:

```powershell
powershell -ExecutionPolicy Bypass -File .\stream-monitor.ps1 -IntervalSeconds 60
```

Бот проверяет Twitch каждые 60 секунд и отправляет анонс **один раз за эфир**, только если подписка `active` и не истекла. Лог: `data/monitor.log`. Если бота нет в канале или нет права поста — в логе будет точная подсказка, остальные стримеры продолжат работать.

Проверить отправку в чат можно так:

```powershell
powershell -ExecutionPolicy Bypass -File .\stream-monitor.ps1 -TestChat 7946867611
```

## Секреты

**Никогда не коммить `.env`** — там токен бота. Для публикации используются переменные окружения:

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота, только на сервере |
| `ADMIN_TOKEN` | секрет для `/announce` |
| `TELEGRAM_CHAT_ID` | резервный чат для тестовых сообщений |
| `BOT_NAME` | имя бота в подписи поста |

## Публикация (Cloudflare Worker)

`worker-public.js` — самодостаточный воркер: внутри него уже лежат HTML/CSS/JS сайта и Mini App.

1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Worker** → **Hello World** → **Deploy**.
2. **Edit code** → замени весь код содержимым `worker-public.js` → **Deploy**.
3. **Settings → Variables and Secrets** → добавить `TELEGRAM_BOT_TOKEN`, `ADMIN_TOKEN`, `TELEGRAM_CHAT_ID`, `BOT_NAME`.
4. Готово:
   - сайт — `https://<имя-воркера>.<аккаунт>.workers.dev/`
   - Mini App — `https://<имя-воркера>.<аккаунт>.workers.dev/app`

Адрес воркера подставляется автоматически: на HTTPS-странице сайт использует свой же origin.

## Важно

GitHub Pages отдаёт только статические файлы: там работают витрина, оплата и Mini App, но **не работают** `/api/state`, `/announce` и автоматические анонсы. Для анонсов держи включённым локальный `server.ps1` + `stream-monitor.ps1` (или задеплой `worker-public.js` на Cloudflare Workers).

Это демо: пароль проверяется на клиенте, сетевые настройки лежат в `localStorage`. Для реального продакшена нужны база данных и серверная авторизация. Токен бота хранится только в `.env` и в серверных секретах — в репозиторий он не попадает.
